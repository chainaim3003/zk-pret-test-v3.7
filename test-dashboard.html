👋 Welcome — here's how to get started

1
Open PowerShell in your project folder:
Right-click inside the folder → "Open in Terminal" or "Open PowerShell window here"
2
Run the test script (copy-paste this exactly):
powershell -ExecutionPolicy Bypass -File .\run-tests-and-log.ps1

To run only one category:
powershell -ExecutionPolicy Bypass -File .\run-tests-and-log.ps1 -Suite compliance
powershell -ExecutionPolicy Bypass -File .\run-tests-and-log.ps1 -Suite risk
3
After the script finishes, a folder called test-run-logs will appear next to this HTML file.
4
Load the logs: Click 📂 Load logs folder above → select the test-run-logs folder → click "Upload" / "Open".
